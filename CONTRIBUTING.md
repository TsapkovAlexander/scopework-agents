# Как предложить изменение

Этот репозиторий — **выгрузка** кода агентов из основного репозитория
Scopework. Каждый выпуск агента выгружается сюда заново, одним коммитом. Поэтому
pull request напрямую сюда не вливается: следующая выгрузка перезаписала бы его.

Что работает:

- **Ошибка или вопрос** — заведите задачу: что ожидали, что получили, версия
  агента (`scopework-agent version`), ОС и архитектура сервера.
- **Предложение правки** — опишите его в задаче или приложите патч. Мы перенесём
  изменение в основной репозиторий, и оно придёт сюда со следующим выпуском;
  в задаче напишем, в каком.
- **Уязвимость** — не в задачи, а по адресу из [SECURITY.md](SECURITY.md).

## Проверить правку у себя

Тесты агента развёртывания:

```bash
cd apps/deploy-agent && go test -count=1 ./...
```

`-count=1` обязателен: тесты читают общие фикстуры вне модуля
(`packages/deploy-core/fixtures`), и кеш Go их правку не видит.

Воспроизводимая сборка и сверка с подписанным выпуском —
[README.md](README.md), раздел «Собери сам и сравни хеш».
